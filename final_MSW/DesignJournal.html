DESIGN JOURNAL
REESE OXNER — NOV TO DEC. 2019

  1. I chose a simple layout for this website, creating a clean template where the services and images of the services could easily be found.
  2. I used PHP include on every element I could, to make the site very easy to update and maintain.
  3. I used CSS, PHP and SQL to generate webpages for each example of my client’s work — this allows him to upload work as he completes it and negates the need to code an individual website for every image.
  4. I used CSS to make the website mobile-friendly.
  5. Creating the grid hovers on the content pages makes the portfolio items eye-catching and enticing.
  6. Using databases will make this site easy to update, maintain and keeps it very consistent.
  7. Using the images as the primary indicator of quality is better because it’s easier to show than tell.
  8. The backend systems are as simplistic as possible for ease of use.
